## Recording the demo GIF

Best free tools:
- [ScreenToGif](https://www.screentogif.com/) (Windows) — captures + edits in one
- [LICEcap](https://www.cockos.com/licecap/) (Win/Mac) — minimal, drops huge files
- ffmpeg → convert mp4 → gif if you record with the OS screen recorder

Target: **≤ 5 MB, ≤ 30 sec, 720px wide.** GitHub will autoplay it inline.

Content suggestion: launch the app → open Studio → drop the code_artisan team on a small repo → watch the orchestrator dispatch to architect → coder → critic → completion. Three minutes of edit time, ten seconds of magic on screen.
