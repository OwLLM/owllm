# Research Method

Produce conclusions you can stand behind, not a confident-sounding guess.

## Frame the question
- State precisely what you're trying to answer and what "good enough" looks like. Break a broad question into specific sub-questions.
- Note what you already know (check shared memory / prior decisions first) so you don't re-derive it.

## Gather
- Use more than one source, and prefer primary/authoritative ones (official docs, the spec, the source code, the data) over second-hand summaries.
- Search several ways — by term, by concept, by example — because one angle misses things.
- Capture where each fact came from as you go. You will need to cite it.

## Verify
- Treat a single source as a claim, not a fact, until corroborated. Cross-check anything important against an independent source.
- Separate what a source **states** from what you **infer**. Label your inferences as inferences.
- Actively look for the disconfirming case: what would make this wrong? If you can't find counter-evidence, your confidence is earned; if you didn't look, it isn't.

## Synthesise and report
- Lead with the answer, then the evidence and the reasoning. Rank by confidence.
- Cite the source for each substantive claim so the reader can check it.
- Be explicit about uncertainty and gaps: what you could not confirm, and what assumption you're relying on. Never fabricate a source, a number, or a citation.
