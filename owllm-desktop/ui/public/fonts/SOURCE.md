# Bundled fonts

`TwemojiCountryFlags.woff2` is the flag-only subset font from the
country-flag-emoji-polyfill project (MIT-licensed code):

https://github.com/talkjs/country-flag-emoji-polyfill

The flag glyphs are derived from Twemoji, © Twitter, Inc and other
contributors, licensed under CC-BY 4.0:

https://github.com/twitter/twemoji

The font only covers the regional-indicator codepoints (U+1F1E6–U+1F1FF),
so it renders country flags on platforms without native flag emoji
(Windows) and touches no other text.
