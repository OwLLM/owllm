# World Map / Solar System textures

The Earth day, normal, specular, and cloud maps in this directory are bundled
from the Three.js example texture set:

https://github.com/mrdoob/three.js/tree/dev/examples/textures/planets

Three.js is distributed under the MIT License. The Earth imagery is derived
from NASA's public Blue Marble datasets.

The seven planet maps (`mercury.jpg`, `venus.jpg`, `mars.jpg`, `jupiter.jpg`,
`saturn.jpg`, `saturn-ring.png`, `uranus.jpg`, `neptune.jpg`) are the 2K set
from Solar System Scope, based on NASA elevation and imagery data:

https://www.solarsystemscope.com/textures/

Solar System Scope textures are distributed under the Attribution 4.0
International license (CC BY 4.0) — https://creativecommons.org/licenses/by/4.0/
Attribution: "Solar System Scope" (www.solarsystemscope.com).

These local copies keep the World Map fully functional offline and avoid
loading third-party assets at runtime.
